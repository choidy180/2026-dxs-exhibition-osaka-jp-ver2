# AI Advisor 대화형 제조 업무 데모

현재 전시회 버전은 외부 AI 서버 없이 주제 탐색, 조건 확인, 후속 질문을 처리합니다. 검수본의 확인된 답변을 보존하고 사용자 요청에 따라 만든 일관된 데모 데이터를 추가했습니다. 검수본 작성일은 **2026-09-18**, 데모 조회 기준일은 **2026-08-21**, 조회 기간은 **2026-08-21~31**입니다. 기존 2026-09-09 내부망 API 실측 문서는 과거 연동 기록입니다.

## 사용 방법

일반 업무 화면의 왼쪽 아래 또는 마스터 대시보드의 오른쪽 아래 **AI Advisor**를 엽니다. 시작 버튼 네 개는 납품·배송, 자재·재고, 생산, 발주·구매의 주제 메뉴입니다. **질문 목록**에서는 전체 21개 업무 흐름을 볼 수 있습니다.

한국어·일본어로 주제나 질문을 직접 입력해도 됩니다. 질문 언어에 맞춰 답변과 추천 질문을 제공하며 UI 언어와 질문 언어는 달라도 됩니다. 버튼, 목록 번호, 코드·자재명·조건 입력을 섞어서 사용할 수 있습니다. 영어 UI와 질문도 제공합니다.

- `납품처` → 납품 질문 5개 → `2번` → 제품 선택 또는 `ADC30068403` 입력 → 납품처 안내.
- `생산` → `3번` → `ADC30068402` → `300` → `7` → 571.97분 → `그럼 10명은?` → 400.38분.
- `生産` → `3番` → `ADC30068402` → `三百個` → `七人` → `では十人なら？`도 같은 조건을 유지합니다.
- `가스켓 재고` 또는 `ガスケットの在庫は？` → 자재 재고 → `공급처는?` → 같은 자재의 권장 발주·공급처.
- 납품·생산 계획 결과 뒤 `내일은?` / `明日なら？`로 날짜를 바꿉니다. `처음으로`, `질문 목록`, `주제 바꾸기`는 주제 선택으로, `다른 질문`은 현재 주제 메뉴로 돌아갑니다.

수량·인원을 묻는 단계에서 숫자만 입력하면 조건 값으로 사용합니다. `1번`·`1番`처럼 명시하면 목록 선택입니다. 오래된 답변의 버튼을 눌러도 해당 답변의 조건을 기준으로 이어갑니다. 화면 하단에 현재 주제·코드·조건을 표시하고 입력 안내를 단계에 맞게 바꿉니다.

## 자동 시연

오른쪽 위 **시연 재생 ON/OFF** 설정에 AI Advisor 집중 구간을 추가했습니다. 전체 재생에서는 메인 관제센터 다음에 소개하며, **AI Advisor부터 시연**으로 바로 시작할 수 있습니다. 짧은 주제 입력, 번호가 붙은 질문 선택, 자재명 입력, 납품 날짜 변경, 재고에서 공급처로 이동, 발주 상세, 제품·수량·인원별 생산 시간과 인원 변경, 관련 질문 안내, 전체 질문 목록을 실제 입력창과 버튼으로 보여줍니다.

입력 중·응답 대기 중에도 OFF와 다음 페이지로 중단할 수 있습니다. 숨긴 탭에서는 타이핑과 읽기 시간을 유지하며 복귀한 뒤 이어갑니다. 시연은 `constants/exhibition-demo.ts`, 설명은 `data/exhibition-demo-copy.ts`, 동작 경계는 `utils/exhibition-playback.ts`에서 관리합니다. `tests/exhibition/advisor-autoplay.test.ts`가 세 언어의 전체 대화, 타이핑 중 취소와 새 답변 대기를 검증합니다.

| MGJ67712807 권장 발주수량·공급처 | 310.0, 엘지전자(주) / LG電子株式会社 | 답변 가능 |

추가 데이터는 제품 4개, 자재/BOM 14개, 부족·발주 자재 10개, 차량 3대입니다. 기준일 납품 840개·포장 완료 720개이며 제품·차량 집계가 일치합니다. 발주 단가 확정 6건의 행 합계가 두 검수 금액과 일치하며, 미산정 4건은 `-`로 유지합니다. 추가한 상세 행은 검수 원본 데이터가 아니므로 **데모 데이터**, 계산 결과는 **시뮬레이션** 배지로 구분합니다. 검수본의 완전한 답변 6개는 원문 수치를 그대로 사용합니다.

생산 시간은 검수본의 두 제품 작업량을 기준으로 `수량 × 표준 인·분 / 작업 인원`으로 계산합니다. 휴게·설비 정지는 별도입니다. 다른 두 제품의 표준 작업량과 BOM 구성은 추가 데모 설정입니다. 재고 시뮬레이션은 부족 예정일 전 양수 재고, 해당 날짜의 검수 부족 수량, 이후 소요량이 일관되도록 구성합니다. ‘오늘’·‘내일’·‘다음 주’는 고정된 데모 기간을 기준으로 합니다.

## 질문 인식과 예외 처리

- NFKC 정규화로 전각 코드·숫자와 검수본의 호환 한자 부수 표기를 처리합니다. 일본어 숫자의 월·일·인원·수량 표기도 지원합니다.
- 문장 부호·띄어쓰기와 일반적인 한국어·일본어 표현 변형을 인식합니다. 범용 언어 모델이 아니므로 임의의 모든 표현을 이해하는 기능은 아닙니다.
- 빠진 코드·수량·인원·날짜는 차례로 질문합니다. 알려진 코드, 한국어·일본어 자재 별칭과 영문 자재명을 인식합니다. 수량은 1~100,000개 정수, 인원은 1~100명이며 잘못된 값은 해당 단계에서 다시 입력하도록 안내합니다.
- 없는 품번, 조회 기간 밖 날짜, 업무 밖 질문은 자연스럽게 선택 가능한 질문이나 품번 목록으로 연결합니다. 여러 업무를 동시에 물으면 먼저 주제를 선택하도록 합니다.
- 여러 질문을 합치면 질문 하나를 선택하도록 안내합니다. 실시간 데이터 요청, 원인 분석, 실제 발주 실행 등은 지원하지 않습니다.
- 빈 입력·2,000자 초과는 UI에서 차단하며 서버 계약에서도 검사합니다. 중복 전송, 취소, 중복 말풍선 없는 재시도와 새 대화를 지원합니다.
- 패널을 닫았다 열면 현재 컴포넌트의 대화와 조건을 유지합니다. 취소·실패는 조건을 확정하지 않으며 재시도는 같은 요청 조건을 사용합니다. 새 대화·새로고침·언어 변경·컴포넌트 언마운트 시 초기화하며 서버 세션·장기 저장은 사용하지 않습니다.

## API 계약

브라우저의 전시용 챗봇은 로컬 함수를 직접 호출합니다. 호환 API 경로도 같은 함수와 자료를 사용합니다. 환경변수에 서버 주소를 설정하는 것만으로 실제 서버에 연결되지 않습니다.

| 경로 | 요청 | 응답 |
| --- | --- | --- |
| POST /api/ai-advisor/chat | `{ query, session_id?, locale?: 'ko' \| 'ja' \| 'en', context? }` | `{ answer, session_id: null, table, status, suggestions?, suggestions_title?, source?, context?, data_kind? }` |
| GET /api/ai-advisor/meta | 없음 | `{ as_of_date: '2026-09-18', snapshot_date: '2026-08-21', forecast_end_date: '2026-08-31' }` |
| POST /api/chat | 기존 `{ message }` | `{ ok: true, answer }` |

상태는 `success`, `menu`, `clarification`, `empty` 및 검수 답변 호환 상태 `partial`, `unavailable`, `unsupported`입니다. `context`는 주제·의도·코드·수량·인원·날짜·대기 조건·선택 목록을 담습니다. API를 통한 후속 질문은 직전 응답의 `context`를 그대로 다음 요청에 전달합니다. 유효한 공개 필드만 보존하고 잘못된 상태·과도한 선택 목록·범위 밖 수치·날짜 형식은 거절합니다. 요청 형식 오류는 기존 400·415·422 응답을 유지합니다.

추천 질문은 `{ id, label, query }`, 출처는 `{ title, slide }`입니다. 기존 표 형식인 `columns / rows / truncated / summary`를 유지합니다. 요청·응답은 캐시하지 않습니다.

## 구현과 검증

- `data/advisor-knowledge.ts`: 12개 질문과 검수된 사실, 언어별 문안, 자료 범위
- `data/advisor-conversation-catalog.ts`: 4개 주제와 21개 대화 흐름
- `data/advisor-demo-dataset.ts`: 사용자 요청으로 추가한 일관된 데모 데이터와 별칭
- `utils/ai-advisor-conversation.ts`: 메뉴·번호 선택·조건 확인·문맥·후속 질문·집계·시뮬레이션
- `utils/ai-advisor-match.ts`: 질문 정규화, 의도·조건 검사, 질문 언어 선택
- `data/demo-advisor.ts`: 답변·요약 표·출처·추천 질문 생성
- `hooks/use-ai-advisor.ts`, `components/ai-advisor/`: 대화 상태와 질문 안내 화면
- `tests/exhibition/advisor.test.ts`: PPT 원문, 수치 보존, 일본어 변형, 자료 밖 조건, 추천 복구, 계약 검증
- `tests/exhibition/advisor-conversation.test.ts`: 세 언어의 전체 흐름, 조건 분할 입력·변경, 번호·별칭·날짜, 데이터 합계·예측 일관성, 상태 계약

`npm run test:exhibition`에 챗봇 회귀 검증이 포함됩니다. UI가 이미 문안을 언어별로 선택하므로 JSX 번역 로더는 챗봇 폴더를 다시 번역하지 않아 사용자 입력과 답변 언어를 보존합니다.
