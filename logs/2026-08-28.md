## 15:43:26 KST — CCTV 상황 모니터링 사내 API 연동

- AI 도구: GPT/Codex
- 간단한 작업 내용: 상황 모니터링 화면이 사내 카메라 API 응답으로 카메라 목록과 썸네일을 표시하도록 연결했습니다. 썸네일 정보가 없거나 이미지 응답이 정상적이지 않으면 카메라 연결 안 됨 화면을 표시합니다.
- 자세한 작업 내용:
  - 브라우저의 CORS·혼합 콘텐츠 문제를 피하도록 카메라 목록과 썸네일을 Next.js 동일 출처 API로 중계했습니다.
  - 카메라 번호, 썸네일 버전, WHEP 경로를 화면 모델로 변환하고 번호에서 동 정보를 추출하도록 응답 매핑을 교체했습니다.
  - 실제 API를 기본 모드로 전환하고 목업은 환경변수로 명시적으로 켤 때만 사용하도록 정리했습니다.
  - 썸네일 버전 누락, URL 누락, HTTP 오류, 이미지가 아닌 응답, 이미지 디코딩 실패를 연결 안 됨 대체 화면으로 통일했습니다.
  - 실제 응답에서 제공하지 않는 설치 위치 대신 카메라 번호, 카메라명, 스트림 경로를 표시하고 WebSocket 안내를 WHEP 메타데이터 안내로 수정했습니다.
  - 선택된 보기 방식은 디자인 가이드에 맞춰 옅은 배경과 사방 1px 테두리로 표시하도록 조정했습니다.
