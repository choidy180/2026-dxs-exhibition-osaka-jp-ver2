  - 미리보기 표는 월 그룹 헤더, 일자 헤더, 요일 헤더 3단과 하단 합계 행을 고정하고, 좌측 식별 컬럼(NO~TOTAL)도 고정해 가로로 스크롤해도 품목을 볼 수 있게 했습니다. 헤더와 본문이 같은 컬럼 정의 하나만 참조합니다.
  - 엑셀 다운로드는 화면에 보이는 표를 그대로 내려받습니다. 월 그룹 병합과 컬럼 폭까지 반영합니다.
  - DB 저장은 요청대로 제외했습니다. 버튼과 호출 경로는 만들어 두고 현재는 "API 연결 후 사용할 수 있습니다" 안내만 표시하며, 설정값 하나를 켜면 실제 저장 호출이 동작합니다.
  - 데이터 계층을 목업과 API 로 분리했습니다. 환경변수로 목업 스위치를 끄면 같은 함수로 실제 엔드포인트를 호출하도록 요청·응답 매핑 코드를 미리 작성해 두었고, 목업 수량은 고정 시드로 생성해 서버·클라이언트 화면이 어긋나지 않게 했습니다.
  - 모든 데이터 영역에 조회 중 / 오류(재시도 버튼) / 비어있음 세 상태를 넣었고, 엑셀 라이브러리의 영문 오류는 한국어 안내로 바꿔 표시합니다.
  - 좌측 네비게이션 '생산관리' 그룹에 '생산계획' 항목을 추가했습니다.
  - 구현 중 디자인 가이드에 없던 값이 필요해 토큰 두 개(그리드 짝수 행 색, 그리드 내부 고정 셀 레이어)를 추가하고, 가이드 본문과 AI 요약 규칙, 변경 이력에 함께 반영했습니다.
