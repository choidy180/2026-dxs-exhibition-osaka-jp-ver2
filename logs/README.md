# AI 작업 로그 작성 규칙

이 폴더는 GPT/Codex와 Claude가 이 프로젝트에서 수행한 작업을 일자별로 기록합니다.

## 파일 규칙

- 기준 시간대: `Asia/Seoul` (KST, UTC+09:00)
- 파일명: `YYYY-MM-DD.md`
- 오늘 파일이 없으면 아래 헤더로 새로 만듭니다.
- 오늘 파일이 있으면 기존 내용을 절대 덮어쓰지 않고 파일 끝에 새 항목을 추가합니다.
- 하나의 사용자 요청에는 대표 에이전트가 통합 항목 하나만 작성합니다.
- 같은 요청을 이어서 수정하는 중이라면 새 항목을 중복 추가하지 말고 기존 항목을 최신 결과로 갱신합니다.
- 로그는 모든 수정과 검증이 끝난 뒤, 사용자에게 최종 응답을 보내기 전에 작성합니다.

```md
# AI 작업 로그 — YYYY-MM-DD

> 기준 시간대: Asia/Seoul (KST, UTC+09:00)
```

## 항목 형식

```md
## HH:mm:ss KST — 한눈에 이해할 수 있는 작업 제목

- AI 도구: GPT/Codex 또는 Claude
- 간단한 작업 내용: 비개발자도 이해할 수 있는 한두 문장
- 자세한 작업 내용:
  - 실제로 수행한 변경이나 조사 내용
  - 중요한 동작 방식과 영향 범위
- 수정한 코드 위치:
  - `상대경로/파일명:줄번호` — 수정한 함수·컴포넌트·설정 설명
- 검증:
  - 실행한 검사와 결과
```

## 작성 원칙

- 줄번호를 확실히 알 수 없으면 상대 경로와 함수명 또는 섹션명을 기록합니다.
- 실제로 AI가 수정한 프로젝트 파일만 기록하며, 기존 사용자 변경사항은 포함하지 않습니다.
- 일자별 로그 파일 자체는 `수정한 코드 위치` 목록에 넣지 않습니다.
- 코드 변경이 없는 분석·설명 작업도 기록하고, 이때는 `없음 (코드 수정 없음)`이라고 적습니다.
- 실패하거나 중단된 작업은 그 사실과 원인을 간단히 기록합니다.
- 비밀번호, 토큰, 인증정보, 개인정보, 원문 프롬프트 등 민감한 내용은 기록하지 않습니다.
